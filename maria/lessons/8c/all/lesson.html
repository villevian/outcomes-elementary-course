Grammar
Would like to

We use would like to + verb to talk about things we want to do – or hope to do. We often write (and say) would as 'd.

I'd like to go to Japan one day. I'm sure it's really interesting.

He'd really like to learn Spanish.

We make negatives using wouldn't like to + verb.

I wouldn't like to do his job! It's hard!

We make questions using Would + person + like to + verb.

Would you like to go in a helicopter?

🇺🇦 would like to = хотів би / хотіла б (мрія, бажання). I'd = I would.
